# Shuttle Bus RSU: ระบบติดตามรถราง มหาวิทยาลัยรังสิต

เว็บแอปพลิเคชันติดตามตำแหน่งรถรางไฟฟ้าและจุดจอด 14 อาคารภายในมหาวิทยาลัยรังสิตแบบเรียลไทม์ พร้อมระบบจัดการเส้นทาง จุดจอด และระบบจำลองพิกัดเดินรถสำหรับผู้ดูแลระบบ

---

## ฟีเจอร์หลัก

- **แผนที่ติดตามรถแบบเรียลไทม์**: แสดงตำแหน่งรถรางบนแผนที่ Leaflet อัปเดตพิกัดสดผ่าน Socket.IO
- **ข้อมูลเส้นทางและจุดจอด**: แสดงลำดับจุดจอด 14 อาคารรอบมหาวิทยาลัย พร้อมข้อมูลสายรถที่ผ่านแต่ละจุด
- **ระบบหลังบ้าน (Admin Dashboard)**: จัดการข้อมูลสายรถ จุดจอด สถานะรถ และเครื่องมือจำลองการส่งพิกัด GPS สำหรับทดสอบ
- **โหมดรันแบบ Standalone**: ใช้งานหน้าเว็บดูแผนที่ได้ทันทีโดยไม่ต้องต่อฐานข้อมูลจริง (มีระบบ fallback ดึงข้อมูลจำลองให้อัตโนมัติ)

---

## Tech Stack

- **Frontend**: Next.js 16 (Turbopack, App Router), React 19, TypeScript, Vanilla CSS, Leaflet Map
- **Backend**: Next.js Route Handlers, Prisma ORM 6.12
- **Database**: PostgreSQL 16 (PostGIS)
- **Realtime Server**: Socket.IO 4.8
- **Testing**: Vitest 5.0

## การติดตั้งและการเริ่มใช้งาน

### 1. โคลนโปรเจกต์และติดตั้ง Dependencies

```bash
git clone <REPOSITORY_URL>
cd ShuttelBus_RSU
npm install
cp .env.example .env
```

### 2. เลือกรูปแบบการรันระบบ

#### แบบที่ 1: รันด่วนสำหรับดูหน้าเว็บ (ไม่ต้องเปิด Database)
เหมาะสำหรับเปิดดูหน้าเว็บ ปรับแต่งหน้าตา UI หรือดูแผนที่จุดจอด:
```bash
npm run dev
```
เปิดบราวเซอร์ที่ [http://localhost:3000](http://localhost:3000) ระบบจะใช้ข้อมูลจำลองของมหาวิทยาลัยรังสิตขึ้นแสดงผลให้ทันที

#### แบบที่ 2: รันเต็มระบบพร้อม Database และ Realtime Socket
เหมาะสำหรับการทดสอบระบบบันทึกพิกัดจริง ฐานข้อมูล ระบบล็อกอิน และหน้าจัดการของ Admin:

```bash
# 1. สตาร์ท PostgreSQL Container ผ่าน Docker
docker compose up -d

# 2. สร้างโครงสร้างตารางและใส่ข้อมูลเริ่มต้น (จุดจอด 14 จุดและสายรถ)
npm run db:deploy
npm run db:seed

# 3. สร้างบัญชี Admin สำหรับเข้าใช้งานระบบหลังบ้าน
npm run db:user -- --username admin --password "admin1234" --role ADMIN

# 4. เริ่มการทำงานของเซิร์ฟเวอร์
npm run realtime   # Terminal 1: เริ่ม Socket.IO Server สำหรับรับส่งพิกัดสด
npm run dev        # Terminal 2: เริ่ม Next.js Web App (Port 3000)
```

เข้าสู่ระบบ Admin ได้ที่ [http://localhost:3000/login](http://localhost:3000/login)

## ความปลอดภัยของระบบ

ระบบมีการป้องกันและตรวจสอบสิทธิ์ในจุดสำคัญตามมาตรฐานความปลอดภัย:

- **การจัดเก็บรหัสผ่าน**: เข้ารหัสผ่านบัญชีผู้ใช้ด้วย bcrypt (Cost factor 12) ไม่มีการเก็บรหัสผ่านเป็นข้อความธรรมดาในฐานข้อมูล
- **การจัดการ Session**: ใช้คุกกี้ `shuttle_session` แบบสุ่ม 32 bytes (SHA-256) พร้อมแฟล็ก `httpOnly`, `sameSite=lax` และ `secure`
- **การป้องกันข้อมูล Database รั่วไหล**: ไม่เปิดเผย `DATABASE_URL` ไปยังฝั่ง client bundle
- **การส่งพิกัดรถ (Telemetry)**: ตรวจสอบ Bearer Token ที่ลงนามด้วย HMAC-SHA256 ป้องกันการปลอมแปลงพิกัดและป้องกันการส่งข้อมูลแทนรถคันอื่น
- **การจัดการทริปเดินรถ**: กำหนดสิทธิ์ให้เฉพาะ Admin หรือรถที่รับมอบหมายเท่านั้นที่สามารถกดเริ่มหรือจบทริปได้
- **Socket Webhook ภายใน**: สื่อสารระหว่าง Backend และ Socket Server ผ่าน HTTP Header รับรองความปลอดภัย `X-Internal-Secret` พร้อมปิดการใช้งาน Wildcard CORS
