## 2. โครงสร้างไฟล์ Mockup ในโฟลเดอร์นี้

- **`rsu-campus-data.json`**: ไฟล์ JSON ข้อมูลดิบ พร้อม Search Keywords และ Description สามารถแก้ไขตัวเลขพิกัดได้ที่นี่โดยตรง
- **`mockData.ts`**: โมดูล TypeScript พร้อมฟังก์ชันช่วยค้นหา:
  ```ts
  import { findStop, getStopByBuilding, getStopById, MOCK_STOPS } from "../mockup/mockData";

  // ค้นหาด้วยชื่อหรือคีย์เวิร์ด
  const results = findStop("วิศวะ");

  // ค้นหาด้วยหมายเลขตึก
  const bldg8 = getStopByBuilding(8);

  // ดึงตาม ID (1 - 14)
  const entrance = getStopById(1);
  ```

## 3. วิธีการรันโปรเจกต์ (รองรับทุกระบบ: macOS, Windows, Linux)

โปรเจกต์นี้ได้รับการออกแบบให้ทำงานแบบ Cross-Platform รันได้ทันทีโดยไม่ต้องกังวลเรื่องระบบปฏิบัติการ:

### แบบที่ 1: รันด่วนโดยไม่ต้องเปิด Database (Mock Mode)
เหมาะสำหรับผู้ที่เพิ่ง Clone ไปและต้องการดูหน้าเว็บ ปรับ UI หรือหาจุดบนแผนที่ทันที:
```bash
npm install
npm run dev
```
เปิดบราวเซอร์ที่: `http://localhost:3000` (ระบบจะดึงพิกัดจาก Mockup ให้โดยอัตโนมัติ)

### แบบที่ 2: รันแบบครบวงจรพร้อม Database และ Realtime Socket
1. เปิด Docker Database (รองรับทั้ง Windows x64, Linux, และ Mac Apple Silicon M-series):
   ```bash
   docker compose up -d
   ```
2. สร้างตารางและใส่ข้อมูลพิกัด (Seed Database):
   ```bash
   npm run db:deploy
   npm run db:seed
   ```
3. เริ่มต้นเซิร์ฟเวอร์ Realtime และ Frontend:
   ```bash
   npm run realtime
   # ในอีก Terminal หนึ่ง:
   npm run dev
   ```
